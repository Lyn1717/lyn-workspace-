        📲 安装到手机桌面（像 App 一样打开）
        想要全屏、离线、带图标的「工作台 App」，需要先把文件放到免费 https 网站，再「添加到主屏幕」。下面两步即可：
        第一步 · 部署（任选其一，免费）
        ① Netlify Drop：电脑打开 app.netlify.com/drop，把本文件夹拖进去，几秒后得到一个 https 网址。
        ② GitHub Pages / Vercel：把 index.html、icon-192.png、icon-512.png 这 3 个文件（sw.js 可选，用于离线）上传到仓库并开启 Pages。
        ③ 部署后把网址发到手机，或直接扫码。
        第二步 · 手机添加
        iOS（Safari）：打开网址 → 底部「分享」→ 添加到主屏幕 → 名称填「Lyn 工作台」。
        Android（Chrome / Edge）：右上角 ⋮ → 添加到主屏幕 / 安装应用。
        安装后桌面出现图标，点开即全屏运行、可离线使用。
        ⚠️ QQ / 微信内置浏览器无法把网页「安装」成独立 App。请用手机自带 Safari（iPhone）或 Chrome（安卓）完成第二步。若暂时不部署，也可在 Android Chrome 里把本文件「添加到主屏幕」作为快捷方式（功能可用，但每次启动会显示欢迎页、剪贴板需长按）。
